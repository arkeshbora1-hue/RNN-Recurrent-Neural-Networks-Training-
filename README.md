# RNN-Recurrent-Neural-Networks-Training-
A hands-on Keras RNN notebook: from a SimpleRNN that learns to count to a reusable toolkit for sequence prediction, time-series forecasting, Shakespeare text generation and LSTM encoder-decoders.
This project starts with a single SimpleRNN predicting the next number in a sequence, then tests where that model breaks. It turns out the model had only learned to “add about 1”. The notebook then builds a reusable RNN toolkit with one model builder covering SimpleRNN, LSTM and GRU, time-ordered splitting and window-relative scaling. The toolkit is applied to four problems: learning arithmetic rules that generalise to unseen and out-of-range inputs (error 0.005), 12-step time-series forecasting that halves a seasonal baseline’s error, character-level Shakespeare generation, and an LSTM encoder-decoder. A pretrained Transformer translation demo and a hidden-state heatmap round it out.
